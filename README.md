## ENSE 281 LAB PORTFOLIO
This repository follows the lab assignments for ENSE 281 Winter 2026. Follows the development of a note posting and voting platform. By the last folder named "LAB 9" it includes user authentication, secured login/logout, secure user registration with password hashing, and runs a live CRUD database.
<hr/>

### Installation guide:
- Ensure node.js and mongoose are installed in computer
- For most labs, run "npm i" in terminal in the base folder to install dependencies
- For Lab 8, run "node app.js" once to create and populate the database in your computer. This database will be used by Lab 9
- Run "node app.js" in terminal to start server. Site runs on localhost:3000
